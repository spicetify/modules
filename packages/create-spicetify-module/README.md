# create-spicetify-module

Scaffold a [Spicetify](https://spicetify.app) v3 module.

```sh
npm create spicetify-module my-module
cd my-module
npm install
npm run dev
```

Add `--template extension`, `app`, or `theme` to start from a different template. The launcher delegates to [`@spicetify/kit`](https://www.npmjs.com/package/@spicetify/kit), whose README covers the dev loop, the scripts, and troubleshooting.
